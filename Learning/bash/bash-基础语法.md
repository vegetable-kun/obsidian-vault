# [[Bash-基础语法]]

> [!tip] 学习目标
> 掌握 Bash 的基本语法，包括变量、循环、函数和常用命令，能够编写简单的脚本自动化任务。

---

## 📋 基本概念

| 概念 | 说明 | 示例 |
|---|---|---|
| Shell | 解释型命令语言 | `bash`, `zsh`, `sh` |
| 变量 | 存储数据 | `name="Hello"` |
| 参数 | 传递给脚本 | `$1`, `$2` |
| 循环 | 重复执行 | `for`, `while` |
| 函数 | 封装代码 | `func() { ... }` |

---

## 🎯 难度分段学习

| 难度 | 目标人群 | 学习建议 | 预估时长 |
|---|---|---|---|
| **入门** | 完全零基础、初次接触 Shell | 重点掌握变量、基本命令、简单脚本，完成 5 个练习题 | 15h |
| **进阶** | 有基础需求自动化任务 | 重点掌握循环、函数、文件处理，编写实用自动化脚本 | 20h |
| **高级** | 需要进行复杂系统运维 | 重点掌握进程管理、网络编程、调试技巧，编写生产级脚本 | 25h |

---

### 入门（Beginner）

| 知识点 | 具体内容 | 练习 |
|---|---|---|
| Shell 介绍 | Shell 的作用、常见类型（bash, zsh） | 写一篇 Shell 介绍 |
| 基本命令 | `ls`, `cd`, `mkdir`, `rm`, `cp`, `mv` | 练习 1：目录管理脚本 |
| 变量 | 定义、引用、只读、unset | 练习 2：问候脚本 |
| 字符串 | 长度、子串、大小写转换 | 练习 3：字符串处理脚本 |
| 条件判断 | 数值比较、字符串比较、文件测试 | 练习 4：判断脚本 |
| 循环 | `for`、`while`、`until` | 练习 5：循环计数 |
| 函数 | 定义、参数、返回值 | 练习 6：函数练习 |

**入门项目**：编写一个 `backup.sh`，自动备份指定目录到 `/tmp/backup/`。

---

### 进阶（Intermediate）

| 知识点 | 具体内容 | 练习 |
|---|---|---|
| 数组 | 定义、遍历、获取长度 | 练习 7：数组练习 |
| 位置参数 | `$1`-`$9`、`$#`、`$*`、`$@` | 练习 8：参数处理脚本 |
| 字符串操作 | 提取、替换、连接 | 练习 9：字符串处理 |
| 文件重定向 | `>`, `>>`, `|`, `2>` | 练习 10：日志切割脚本 |
| `sed` 和 `awk` | 基本文本处理 | 练习 11：文本提取 |
| 信号处理 | `trap`、`kill` | 练习 12：信号处理 |
| 环境变量 | `PATH`, `export` | 练习 13：环境配置 |

**进阶项目**：编写 `monitor.sh`，监控磁盘使用情况，当使用率超过 80% 时发送警告。

---

### 高级（Advanced）

| 知识点 | 具体内容 | 练习 |
|---|---|---|
| 进程管理 | `ps`、`top`、`kill`、`nice` | 练习 14：进程监控 |
| 网络编程 | `curl`、`wget`、`nc` | 练习 15：网络状态检查 |
| 进程间通信 | `pipe`、`fifo` | 练习 16：FIFO 通信 |
| 调试技巧 | `set -x`、`bash -n` | 练习 17：调试脚本 |
| 并发与锁 | `flock`、`&` | 练习 17：并发安全脚本 |
| 系统调用 | `open`、`read`、`write` | 练习 18：系统信息收集 |
| 包管理 | `apt`、`yum`、`brew` | 练习 19：包管理脚本 |

**高级项目**：编写 `system-audit.sh`，生成系统完整审计报告（内存、磁盘、进程、网络状态）。

---

> [!tip] 学习路径建议
> - **零基础**：先完成入门所有练习（约 15h），确保能写出基本脚本
> - **有一定经验**：重点突进进阶章节（约 20h），重点掌握自动化脚本
> - **进阶用户**：挑选高级项目（约 25h），针对实际场景定制脚本

> [!warning] 避坑指南
> - **不要**一开始就学习高级特性，务必扎实基础
> - **练习**要多写脚本，多碰壁才能进步
> - **阅读**开源脚本，学习他人的写法和技巧
